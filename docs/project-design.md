# ChangeGuard Product Design

ChangeGuard 是一个 Governed / Reliable AI Coding Agent：它既能通过模型、规划、上下文、记忆、Runtime 和工具完成受控编码任务，也通过 Contract、Policy、Workspace 隔离、Validator、Trace、Repair 与 Evaluation 提供可靠性治理。

ChangeGuard 将 Coding Agent 执行、治理控制与结果验证组合在同一条可审计流程中。

产品价值是让真实模型自治仍处于可解释、可约束、可验证的闭环中：模型负责语义选择，Runtime 负责受控执行，Governance 负责约束与最终 correctness gate。

当前不建设插件市场、通用 RAG / Vector DB、Model Router、多 Agent、分布式 Runtime、Event Sourcing、Resume Engine、通用工作流或复杂审批框架。演进必须由真实运行证据触发。
